KumikiHub 使い方ガイド

PC 内の複数の Blender バージョンと、そのアドオン・設定・プロジェクトをまとめて管理します。Blender 本体は一切変更しません。

1インストールと初回起動

動作環境
OSWindows 11（64bit）
Windows 10（64bit）でも理論上動作しますが、十分にテストしていないため、すべての機能の動作は保証しません。
Blender2.93 以降、および Bforartists・Goo Engine・UPBGE などの派生版
  1. ダウンロードした zip を好きな場所に展開します（例：デスクトップや D:\Tools）。インストールは不要です。
  2. KumikiHub.exe をダブルクリックします。
  3. 表示言語を選びます（初期値は English。あとで「設定 → 一般」で変更できます）。
  4. ようこそ画面で「パソコンをスキャン」を押すと、PC 内の Blender を自動で見つけます。
「Windows によって PC が保護されました」と表示されたら
「詳細情報」→「実行」を押してください。初回だけです。
まず試してみたい場合
KumikiHub Demo.bat をダブルクリックすると、サンプルデータで起動します。実際の Blender や設定は読み込まず、変更もしません。

基本の考え方

BlenderインスタンスPC 内の各 Blender（バージョン違い・ポータブル版・派生版）
アドオンライブラリすべてのアドオンとそのバージョンを 1 か所に保管
モジュール一緒に使うアドオンのまとまり（例：「スカルプト」「VRM」）
起動Blender ごとに選んだモジュールのアドオンだけを読み込む

ショートカット：Ctrl+K 機能検索　Ctrl+, 設定を開く　F5 再読み込み

2Blenderインスタンス

Blender ごとにカードを表示します。バージョン、選んだモジュール、設定の場所、最後に起動した日時が分かります。右上でカード / リスト表示を切り替えられます。

やりたいこと方法
起動する「▶ 起動」を押すか、カードをダブルクリック
Blender が見つからない「インストールをスキャン」横の矢印 → すべて / 指定したドライブをスキャン。または「手動で追加」で blender.exe を選ぶ、フォルダーをウィンドウにドラッグ
この Blender で読み込むモジュールを決める「管理 → アドオン → モジュールを選ぶ」（複数選択可）
今回だけ別のモジュールで起動「モジュールを選んで起動」
今回だけ起動オプションを追加一時的な起動オプション欄に入力
公式版をダウンロード「新しい Blender をダウンロード」（Daily / Experimental Builds も可）

「管理」メニュー（よく使う項目はカードの右クリックにもあります）

サブメニュー内容
アドオンモジュールを選ぶ、アドオン一覧（インストール済みアドオンの確認と有効 / 無効）、アドオンのバージョンを一括最適化、アドオンのヘルスチェック
設定とバックアッププリファレンスとキーマップ（5 章）、設定のバックアップ / 復元、設定を他のBlenderインスタンスにコピー、起動スクリプト（.bat）を書き出す
インストールと移動ポータブルの有効 / 無効、管理フォルダーへ移行、新しいBlenderインスタンスとして複製、この Blender をアンインストール
その他一番上に固定、最近開いたファイル、前回の起動レポート、退避エリア

元に影響しない Blender のコピーを作る

「新しいBlenderインスタンスとして複製」は Blender 全体を管理フォルダーにコピーし、初期設定でポータブルを有効にして現在の設定もコピーします。以後は設定・アドオン・選んだモジュールがそれぞれ独立するので、「VRM 用」「新しいアドオンの試用」などに便利です。

設定の場所にオレンジの「共有！」と表示される
同じシリーズの他のバージョンと設定を共有しています。分けるには「ポータブルを有効にする（設定を独立）」を使います。

「リストから削除」はファイルを削除しません。「この Blender をアンインストール」はまず退避エリアに移すので、元に戻せます。

3アドオンライブラリ

すべてのアドオンを 1 か所にまとめ、同じアドオンの複数バージョンを保管できます。名前の左の「+」で各バージョンを表示します。

アドオンを追加する

  • アドオンを追加：.zip / .rar / .7z、フォルダー、.py を読み込みます。ウィンドウにドラッグしても追加できます。
  • Blender にインストール済みのアドオンを読み取る：各 Blender にすでに入っているアドオンをライブラリに取り込みます。Blender 内蔵のアドオンは初期状態でチェックが外れています。
  • 公式エクステンション：検索・ダウンロード・更新確認、他の Blender 用のバージョンの取得ができます。
  • Superhive：「設定 → アカウントと API」に API トークンを貼り付けると、購入済みアドオンの全バージョンを取得し、更新を確認できます。

一覧の見方

列 / 表示意味
Blender シリーズ列の丸使用可 不明 使用不可。マウスを乗せると理由が分かります。右クリックで「動作確認済み / 動作不可」を手動でマークできます。
追加日アドオンをライブラリに追加した日付です。
青の太字 + NEW最近追加したアドオンです（まとめて追加したものは一緒に表示）。次に追加すると、新しく追加したものに移ります。
種類「Blender 内蔵」（太字）Blender に付属するアドオン、または 4.2 から公式エクステンションに移った元内蔵アドオンです。通常はモジュールに入れる必要はありません。
種類「アドオンではない」（グレー）bl_info がないため Blender は読み込みません。多くの場合、別のアドオンを間違った場所に展開したときに残った部品です（例：core、utils）。
  • 並べ替え：列名をクリックで並べ替え、もう一度で逆順、3 回目で元の順に戻ります。次回も同じ並び順で開きます。
  • 表示名を変更：アドオンを右クリック →「表示名を変更」。変わるのは画面上の名前だけで、ストアとの照合や更新確認には元の名前を使います。空欄にすると元の名前に戻ります。
  • フォルダー名が違う同じアドオン：作者がバージョンごとにフォルダー名を変えた場合（例：TexTools_1_5 と textools）も、元の名前でまとめて 1 行に表示します。

チェックとツール

  • アドオンのヘルスチェック：バックグラウンドで実際に読み込み、動かないアドオンや競合・クラッシュの原因を見つけます。
  • アップグレードアシスタント：新しい Blender に移る前に、更新が必要なアドオンを確認します。
  • アドオンではない項目を整理：bl_info がない項目を一覧表示し、2 回確認したうえで退避エリアに移します。
  • バックアップ：ライブラリ全体を 1 つのファイルにまとめる、またはバックアップから復元します。

4モジュール

一緒に使うアドオンのまとまりです（例：「スカルプト」「リギング」「VRM」）。Blender ごとに選んだモジュールのアドオンだけを読み込むので、Blender ごとに入れ直す必要はありません。

  1. 「モジュール」タブで「追加」を押し、名前を付けます。
  2. 入れるアドオンにチェックを入れます（自動的に保存されます）。
  3. 「Blenderインスタンス」→「管理 → アドオン → モジュールを選ぶ」で、Blender ごとに使うモジュールを選びます。
  • 使うバージョン：「自動（推奨）」にすると、起動時にその Blender に最適なバージョンを自動で選びます（緑を優先、赤はスキップ）。特定のバージョンに固定することもできます。
  • 互換性：右の列に、上で選んだ Blender バージョンで使えるかを表示します。
  • 並べ替えと NEW：アドオンライブラリと同じく、列名で並べ替えができ、「追加日」列があり、最近追加したものには NEW が付きます。
  • 同じアドオンは 1 行：バージョンごとにフォルダー名が変わった同じアドオンも 1 行にまとめられ、1 回チェックするだけで済みます。
モジュールが決めるのは「どのアドオンを読み込むか」だけです。プリファレンスとキーマップは常にその Blender 自身のものを使い、モジュールによって変わることはありません。

5プリファレンスとキーマップ

「Blenderインスタンス」→「管理 → 設定とバックアップ → プリファレンスとキーマップ」。プリファレンスとキーマップをバックアップしたり、他の Blender に持っていったりできます。

やりたいこと方法
名前を付けてバックアップ名前を入力 →「現在の設定をバックアップ」。プリファレンス（プリファレンスで変更したキーマップを含む）とキーマップのプリセットファイルを選べます。
同じバージョンの他の Blender に移すバックアップを選ぶ（または現在の設定をそのまま使う）→ 適用先の Blender にチェック →「チェックした Blender に適用」。
新しいバージョンの Blender に引き継ぐ同上。新しい Blender を初めて開いたときに、古い形式が自動で変換されます。
  • 元より古いバージョンには適用できません（古い Blender は新しい設定ファイルを読めないため）。
  • 適用前に適用先の現在の設定を自動でバックアップし、置き換えたファイルは退避エリアに移します。
  • 適用先の Blender は先に閉じてください。

6プロジェクト

作品フォルダー、工程、使う Blender をひとまとめにします。

  1. 「追加」で作品フォルダーを選びます。テンプレートも使えます（例：VTuber モデル：モデリング → UV → テクスチャ → リギング）。
  2. 工程ごとに使う Blender と、モジュールの指定（「この Blender でチェックしたモジュール」または「この工程では下でチェックしたモジュールを使う」）を決めます。
  3. 工程の「起動」を押すと、設定した環境で開きます。
  • .blend ファイル：ダブルクリックすると、前回の工程でそのファイルを開きます。右クリックで別の工程を選べます。
  • レンダリング結果：render、output などのフォルダーにある画像を表示します。
  • 作業時間：工程から開いた Blender を閉じると、時間が自動で記録されます。

7リソースライブラリ

アドオンに付属する素材（モデル、マテリアル、HDRI など）を 1 つだけ保管し、複数の Blender で共有します。

  • リソースライブラリを追加：素材フォルダーと対応するアドオンを指定します。
  • アドオンから共有用に抽出：各バージョンで重複している素材を 1 つにまとめます。

8ログと診断

KumikiHub から Blender を起動するたびにログが残ります。Blender でエラーやクラッシュが起きると、原因を自動で分析して対処法を提案します（例：あるアドオンを無効にする）。

  • 「問題があるものだけ表示」にチェックで絞り込めます。
  • 「設定 → アカウントと API」にご自身の AI API キーを入力すると、「AI 詳細分析」で競合の原因を調べられます（料金は AI サービスから直接請求されます）。
  • 同じ問題の通知が不要なら、通知ウィンドウで「同じ問題は次回から表示しない」にチェックします。
  • ファイルのロック：「保存できない / アクセス拒否」と出る場合、多くは Dropbox・OneDrive・ウイルス対策ソフトがそのファイルを使用中です。同期が終わってから保存し直すか、同期しないフォルダーに移してください。

9開発者モード

アドオン開発者向けです。「設定 → 自動化と連携」の一番下で有効にすると、「開発者」タブが追加されます。

形式チェックbl_info / blender_manifest.toml
テンプレートから作成従来のアドオンまたはエクステンション
クリーンな環境で起動このアドオンだけを有効にし、出力をリアルタイム表示
全バージョンで実測各 Blender のバックグラウンドで 1 回ずつ読み込み
リンクインストール編集後に Blender を再起動するだけで反映
パッケージ化zip にまとめる、またはエクステンションとしてビルドして検証

新しい PC に移行する

  • 設定パック：「設定 → 一般」で .bmpack を書き出し、新しい PC で読み込みます。「新しいPCへ移行（自分用）」では、Blenderインスタンスの一覧（選んだモジュールを含む）、プリファレンスとキーマップのバックアップ、モジュール、外観テーマを持っていけます。アドオンのファイルも含められます。「他の人と共有」では、PC のパスやアドオンのファイルは含めません。
  • 転送コード / QR コード：一覧（各 Blender で使うモジュール）だけを送ります。相手の PC に貼り付けると同じ構成を作り、足りないアドオンも一覧表示します。
  • LAN 転送：同じネットワークの 2 台で、片方が「LAN で共有」、もう片方が「LAN から受け取る」を押し、6 桁のコードを入力します。

複数の PC で共有する

「データの場所」を Dropbox、OneDrive、Google ドライブ内のフォルダーにし、他の PC も同じフォルダーを指定すると、アドオンライブラリ・モジュール・プリファレンスのバックアップを共有できます。

11バックアップと退避エリア

  • 自動バックアップ：定期的に、また一括最適化・移動・プリファレンスの適用・復元の前に自動でバックアップします。
  • 退避エリア：削除した設定・アドオン・フォルダーはまずここに移り、元に戻せます。
  • 元に戻す：削除や整理のあと、ステータスバーに「元に戻す」ボタンが表示されます。

12更新・データ・アンインストール

更新：新しいバージョンが出ると、KumikiHub を開いたときにお知らせします（確認は 1 日 1 回まで。「設定 → 自動化と連携」でオフにできます）。購入したストアから新しいバージョンをダウンロードし、古いフォルダーに上書き展開するだけで、設定はそのまま残ります。

内容場所
アプリの設定、Blender の一覧KumikiHub.exe と同じ場所の data フォルダー
アドオンライブラリ、モジュール、プリファレンスのバックアップ、バックアップ「設定 → データの場所」に表示されるフォルダー（初期値 C:\Blender\Addon Archive Area）
キー、起動ログ%LOCALAPPDATA%\BlenderManager（この PC 専用）

13よくある質問

Blender が変更されることはありますか？
Blender 本体は一切変更しません。設定やアドオンを変更する前に自動でバックアップし、削除したものはまず退避エリアに移します。
「Blender 内蔵」「アドオンではない」と表示されるアドオンがあるのはなぜですか？
「Blender 内蔵」は Blender に最初から入っているアドオンで、参考としてライブラリに残しておけます。「アドオンではない」は bl_info がないフォルダーやファイルで、Blender は読み込みません。「チェックとツール → アドオンではない項目を整理」で退避エリアに移せます。
モジュールでプリファレンスが変わりますか？
変わりません。モジュールは読み込むアドオンを決めるだけで、プリファレンスとキーマップは常にその Blender 自身のものです。プリファレンスを移すには 5 章の機能を使ってください。
Steam 版 Blender は使えますか？
現在はスキャン時に Steam 版をスキップします。
不具合の報告方法は？
「バージョン情報」→「診断パックを書き出す」で作成したファイルを cansss2023@gmail.com に送ってください（日本語で大丈夫です）。API キーやパスワードは含まれません。
