KumikiHub 使用說明

把電腦上的多個 Blender 版本、Addon、設定和專案集中管理。不會修改 Blender 本體。

1安裝與第一次開啟

系統需求
作業系統Windows 11（64 位元）
Windows 10（64 位元）理論上可以執行，但未經完整測試，不保證每項功能都能正常運作。
Blender2.93 以後的版本，以及 Bforartists、Goo Engine、UPBGE 等分支版本
  1. 把下載的 zip 解壓到任何位置，例如桌面或 D:\Tools。不需要安裝。
  2. 雙擊 KumikiHub.exe。
  3. 選擇介面語言（預設 English，之後可在「設定 → 一般」更改）。
  4. 歡迎畫面按「掃描我的電腦」，自動找出電腦上的 Blender。
出現「Windows 已保護您的電腦」？
按「其他資訊」→「仍要執行」。只有第一次需要。
只想先看看？
雙擊 KumikiHub Demo.bat，用示範資料開啟，不會讀取或改動你的 Blender 和設定。

基本概念

Blender 實例電腦上的每一個 Blender（不同版本、可攜版、分支版）
Addon 庫所有 Addon 和它們的各個版本，只存一份
模塊一組常一起用的 Addon，例如「雕刻」「VRM」
啟動Blender 勾了哪些模塊，啟動時就只載入那些 Addon

快捷鍵：Ctrl+K 搜尋功能　Ctrl+, 開啟設定　F5 重新整理

2Blender 實例

每個 Blender 是一張卡片，顯示版本、勾選的模塊、設定位置和上次啟動時間。右上角可切換卡片 / 清單。

想做的事方式
啟動按「▶ 啟動」或雙擊卡片
沒找到某個 Blender「掃描安裝」旁的箭頭 → 掃描全部或指定磁碟；或「手動新增」選 blender.exe；或把資料夾拖進視窗
設定這個 Blender 要載入哪些模塊「管理 → Addon → 勾選模塊」（可複選）
這次臨時換一組模塊「選擇模塊後啟動」，只用這一次
這次加啟動參數在「臨時啟動參數」輸入，只用一次
下載官方版本「下載新版 Blender」（含 Daily / Experimental Builds）

「管理」選單（卡片上按右鍵也有常用項目）

子選單內容
Addon勾選模塊、Addon 總覽（查看並啟用 / 停用已安裝的 Addon）、一鍵優化 Addon 版本、Addon 健檢
設定與備份偏好設定與快捷鍵（見第 5 節）、備份 / 還原設定、複製設定到其他 Blender 實例、匯出啟動腳本（.bat）
安裝與搬移啟用 / 停用 Portable、遷移到管理資料夾、複製為新 Blender 實例、解除安裝這個 Blender
其他釘選在最上面、最近開過的檔案、上次啟動報告、備援區

複製一個互不影響的 Blender

「複製為新 Blender 實例」會複製整個 Blender 到管理資料夾，預設同時啟用 Portable，並複製目前的設定。之後兩邊的設定、Addon、勾選的模塊各改各的，適合準備「VRM 用」「試新 Addon 用」的版本。

設定位置顯示橘色「共用！」
這個 Blender 和同系列的其他版本共用設定。要分開請用「啟用 Portable（設定獨立）」。

「從清單移除」不會刪檔案；「解除安裝這個 Blender」會先移到備援區，可以還原。

3Addon 庫

所有 Addon 集中放一份，同一個 Addon 可保留多個版本。按名稱左邊的「+」展開看各版本。

加入 Addon

  • 新增 Addon：匯入 .zip / .rar / .7z、資料夾、.py，或直接把檔案拖進視窗。
  • 從 Blender 讀取已安裝的 Addon：把各個 Blender 裡已經裝好的 Addon 收進庫裡。Blender 內建的 Addon 預設不勾選。
  • 官方 Extensions：搜尋、下載、檢查新版，或下載適用其他 Blender 版本的版本。
  • Superhive：在「設定 → 帳號與 API」貼上 API Token 後，可補齊已購買 Addon 的所有版本，並檢查更新。

看懂清單

欄位 / 標示意思
Blender 系列欄的圓點可用 不確定 不可用。滑鼠移上去看原因；按右鍵可手動標記「已確認可用 / 不可用」。
加入日期這個 Addon 加入 Addon 庫的日期。
藍色粗體 + NEW最近一次加入的 Addon（一次加入好幾個也一起標示）。下次再加入時換成新的那一批。
類型「Blender 內建」（粗體）Blender 本來就附帶的 Addon，或 4.2 起改放到官方 Extensions 平台的原內建 Addon。通常不需要放進模塊。
類型「不是 Addon」（灰色）沒有 bl_info，Blender 不會載入。多半是某個 Addon 解壓到錯誤位置留下的零件（例如 core、utils）。
  • 排序：按欄位名稱排序，再按一次反過來，第三次回到原本順序。下次開啟會記住。
  • 自訂名稱：在 Addon 上按右鍵 →「自訂名稱」。只改畫面上的名稱；比對商店、檢查更新時仍用原名。清空就改回原名。
  • 同一個 Addon 不同資料夾名稱：作者在不同版本改過資料夾名稱時（例如 TexTools_1_5 和 textools），會依原名收在同一列。

健檢與工具

  • Addon 健檢：在背景實測 Addon 能否載入，找出互相衝突或造成閃退的 Addon。
  • 升級助手：換新版 Blender 前，檢查哪些 Addon 需要更新。
  • 清理不是 Addon 的項目：列出沒有 bl_info 的項目，確認兩次後移到備援區。
  • 備份：把整個 Addon 庫打包成一個檔案，或從備份還原。

4模塊

一組常一起用的 Addon，例如「雕刻」「綁定」「VRM」。Blender 勾了哪些模塊，啟動時就只載入那些 Addon，不用每個 Blender 各裝一套。

  1. 在「模塊」分頁按「新增」，取個名字。
  2. 勾選要放進去的 Addon（勾了就自動儲存）。
  3. 到「Blender 實例」→「管理 → Addon → 勾選模塊」，替每個 Blender 勾選要用的模塊。
  • 使用版本：選「自動（建議）」時，啟動時自動挑最適合該 Blender 的版本（綠色優先，紅色略過）。也可以固定某個版本。
  • 相容性：右欄顯示在上方所選 Blender 版本是否可用。
  • 排序與 NEW：和 Addon 庫一樣，可以按欄位名稱排序，有「加入日期」欄，最近加入的顯示 NEW。
  • 同一個 Addon 一列：不同版本改過資料夾名稱的同一個 Addon，也會收在同一列，勾一次就好。
模塊只決定「載入哪些 Addon」。偏好設定與快捷鍵一律用這個 Blender 自己的，不會被模塊改動。

5偏好設定與快捷鍵

在「Blender 實例」→「管理 → 設定與備份 → 偏好設定與快捷鍵」。可以把偏好設定和快捷鍵備份起來，或帶到其他 Blender。

想做的事方式
備份並命名輸入名稱 →「備份目前設定」。可以只選偏好設定（含在偏好設定裡改過的快捷鍵），或只選快捷鍵預設檔。
平移到同版本的其他 Blender選一份備份（或「直接用目前的設定」）→ 勾選目標 Blender →「套用到勾選的 Blender」。
轉移到更新版本的 Blender同上。第一次開啟新版 Blender 時會自動轉換舊格式。
  • 不能套用到比來源更舊的版本（舊版讀不懂新版的設定檔）。
  • 套用前會自動備份目標原本的設定，被取代的檔案移到備援區。
  • 目標 Blender 必須先關閉。

6專案

把作品資料夾、工序和要用的 Blender 綁在一起。

  1. 「新增」選擇作品資料夾，可套用範本（例如 VTuber 模型：建模 → UV → 材質 → 綁定）。
  2. 每個工序指定要用的 Blender，以及模塊來源：「用這個 Blender 勾選的模塊」，或「這個工序改用下面勾選的模塊」。
  3. 按工序的「啟動」，用設定好的環境開啟。
  • .blend 檔案：雙擊會用上次的工序開啟那個檔案；按右鍵可選其他工序。
  • 算圖成品：顯示 render、output 等資料夾裡的圖片。
  • 時間統計：從工序開啟的 Blender 關閉後自動記錄時間。

7資源庫

Addon 附帶的素材（模型、材質、HDRI 等）只存一份，多個 Blender 共用。

  • 新增資源庫：指定素材資料夾和對應的 Addon。
  • 從 Addon 抽出共用：把各版本重複的素材合併成一份。

8記錄與診斷

每次從 KumikiHub 啟動 Blender 都會留下記錄。Blender 出錯或閃退時，會自動分析原因並給出建議（例如停用某個 Addon）。

  • 勾選「只顯示有問題的」快速篩選。
  • 在「設定 → 帳號與 API」填入你自己的 AI API Key，可用「AI 深入分析」判斷衝突原因（費用由該 AI 服務向你收取）。
  • 同一問題不想再收到通知：在通知視窗勾選「同樣的問題下次不再提示」。
  • 檔案被鎖住：出現「無法存檔 / 沒有權限」時，多半是 Dropbox、OneDrive 或防毒軟體正在使用該檔案。等同步完成再存一次，或把檔案移到不同步的資料夾。

格式檢查bl_info / blender_manifest.toml

10設定與搬移

分類內容
一般語言、掃描位置、設定包匯出 / 匯入、跨電腦傳輸
外觀主題配色、字體、介面密度、背景、導覽列位置

自動與整合自動檢查更新、自動備份、通知、檔案總管右鍵選單、系統列、開發者模式

搬到新電腦

  • 設定包：「設定 → 一般」匯出 .bmpack，到新電腦匯入。「搬到新電腦」會帶走 Blender 實例清單（含勾選的模塊）、偏好設定與快捷鍵備份、模塊、外觀主題，也可以包含 Addon 檔案。「分享給別人」不帶你的電腦路徑和 Addon 檔案。
  • 傳輸碼 / QR Code：只傳清單（每個 Blender 勾了哪些模塊），對方貼上後自動建立，並列出還缺哪些 Addon。
  • 區網直傳：同一網路的兩台電腦，一台「分享到區網」，另一台「從區網接收」，輸入 6 位數配對碼。

多台電腦共用

把「資料位置」設到 Dropbox、OneDrive 或 Google Drive 裡的資料夾，其他電腦也指向同一位置，就能共用 Addon 庫、模塊和偏好設定備份。

11備份與備援區

  • 自動備份：定期，以及一鍵優化、搬移、套用偏好設定、還原之前都會自動備份。
  • 備援區：刪除的設定、Addon 和資料夾先移到這裡，可以還原。
  • 復原：移除或清理後，狀態列會出現「復原」按鈕。

12更新、資料與解除安裝

更新：有新版本時，開啟 KumikiHub 會通知你（一天最多檢查一次，可在「設定 → 自動與整合」關閉）。到購買的商店下載新版，解壓覆蓋舊資料夾即可，設定會保留。

內容位置
軟件設定、Blender 清單KumikiHub.exe 旁邊的 data 資料夾
Addon 庫、模塊、偏好設定備份、備份「設定 → 資料位置」顯示的資料夾（預設 C:\Blender\Addon Archive Area）
金鑰、啟動記錄%LOCALAPPDATA%\BlenderManager（只屬於這台電腦）

解除安裝：刪除 KumikiHub 資料夾即可。若也要刪除資料，再刪除上表的另外兩個資料夾。Blender 本身不受影響。

13常見問題

會改動我的 Blender 嗎？
不會修改 Blender 本體。設定與 Addon 的變更都會先備份，刪除的東西先放進備援區。
為什麼有些 Addon 顯示「Blender 內建」或「不是 Addon」？
「Blender 內建」是 Blender 本來就有的 Addon，可以留在庫裡參考。「不是 Addon」是沒有 bl_info 的資料夾或檔案，Blender 不會載入，可以用「健檢與工具 → 清理不是 Addon 的項目」移到備援區。
模塊會改到我的偏好設定嗎？
不會。模塊只決定載入哪些 Addon；偏好設定與快捷鍵一律用這個 Blender 自己的。要搬移偏好設定，請用第 5 節的功能。
Steam 版 Blender 可以用嗎？
目前掃描時會略過 Steam 版。
怎麼回報問題？
「關於」→「匯出診斷包」，把產生的檔案寄到 cansss2023@gmail.com。診斷包不含 API Key 或密碼。
