KumikiHub User Guide

Manage all the Blender versions on your PC, plus their add-ons, settings and projects, in one place. KumikiHub never modifies Blender itself.

1Install & first launch

Requirements
WindowsWindows 11 (64-bit)
Windows 10 (64-bit) should work, but it isn't fully tested, so some features may not work perfectly.
Blender2.93 or later, plus forks such as Bforartists, Goo Engine and UPBGE
  1. Unzip the download anywhere, for example your Desktop or D:\Tools.
  2. Double-click KumikiHub.exe.
  3. Choose your language (English is selected by default; you can change it later in Settings → General).
  4. The welcome screen finds the Blender versions on your PC and adds them to the list.
"Windows protected your PC"?
Click "More info" → "Run anyway". You only need to do this once.
Just want to look around?
Double-click KumikiHub Demo.bat. It opens with sample data and doesn't read or change your Blender or settings.

Shortcuts: Ctrl+K search features　Ctrl+, open Settings　F5 refresh

3Add-on library

Keep one copy of every add-on in one place, with as many versions of each as you like.

  • Adding: "Add add-ons" imports a .zip, folder or .py. You can also read add-ons from an installed Blender, or drag a .zip into the window.
  • Compatibility dots: each column is one Blender series. works unsure doesn't work. Hover to see why.
  • Official Extensions: search, download and check for updates.
  • Superhive: paste your API token in Settings → Accounts & API to fetch every version of the add-ons you bought and check for updates.
  • Checks & tools: test whether add-ons load, and find add-ons that conflict or cause crashes, all in the background.
  • Backup: pack the whole library into one file, or restore from a backup.

4Modules

A set of add-ons you use together, such as "Sculpting", "Rigging" or "VRM". Load only the modules you need at launch, instead of installing everything into every Blender.

  • Tick an add-on to put it in the module.
  • "Automatic (recommended)" picks the best version for each Blender at launch (green first, red skipped). You can also pin a specific version.
  • The right column shows whether each add-on works in the Blender version selected above. After testing, right-click an add-on to mark it "confirmed working" or "confirmed not working".

5Profiles

A separate set of preferences, keymaps and default modules, for example "Modeling" or "VTuber".

  1. Click "Add" to create a profile and tick the modules it should load by default.
  2. In Blender Instances → "Edit", assign the profile to a Blender.
  • Preferences are stored per Blender series (4.2, 4.5…). Modules are shared across all series.
  • "Import current settings from a Blender instance" copies an existing Blender's settings into the profile.

6Projects

Tie a project folder, its stages and the Blender you use for each one together.

  1. Click "Add", choose the project folder and optionally a template (for example a VTuber model: modeling → UV → texturing → rigging).
  2. Give each stage a Blender, profile and modules.
  3. Click "Launch" on a stage to open it with that setup.
  • .blend files: double-click to open with the last stage used; right-click to pick another stage.
  • Renders: shows images from folders such as render and output.
  • Time tracking: time is recorded automatically when a Blender opened from a stage is closed.

7Resources

Keep one copy of the assets that come with add-ons (models, materials, HDRIs…) and share it across every Blender.

  • Add resource library: point to an asset folder and the add-on it belongs to.
  • Extract shared from add-on: merge duplicated assets from different versions into one copy.

8Logs & diagnosis

Every Blender launched from KumikiHub is logged. If Blender reports errors or crashes, KumikiHub analyzes the cause and suggests a fix, such as turning off a specific add-on.

  • Tick "Only runs with problems" to filter quickly.
  • Add your own AI API key in Settings → Accounts & API to use "AI analysis" for finding conflicts. The AI provider bills you directly.
  • To stop alerts for the same problem, tick "Don't show this again for the same problem" in the alert.

Moving to a new PC

  • Settings pack: Settings → General → "Export settings pack" creates a .bmpack file. Import it on the new PC. It includes profiles, modules, preferences and add-on files.
  • Transfer code / QR code: sends only the list. Paste it on the other PC and KumikiHub rebuilds the setup and lists any missing add-ons.
  • Local network: with both PCs on the same network, click "Share on local network" on one and "Receive from local network" on the other, then enter the 6-digit pairing code.

Sharing between PCs

Set the Data location to a folder in Dropbox, OneDrive or Google Drive and point your other PCs to the same folder. They'll share the add-on library, modules and profiles.

11Backups & Safety Bin

  • Auto backup: runs on a schedule, and before optimizing, moving or restoring.
  • Safety Bin: deleted settings and folders go here first, so you can restore them.
  • Undo: after removing something from a list, an "Undo" button appears in the status bar.

12Updates, data & uninstall

Updates: KumikiHub tells you when a new version is out (it checks at most once a day; turn it off in Settings → Automation & integration). Unzip the new version over the old folder. Your settings are kept.

WhatWhere
App settings, Blender listThe data folder next to KumikiHub.exe
Add-on library, profiles, backupsThe folder shown in Settings → Data location (default C:\Blender\Addon Archive Area)
Keys, launch logs%LOCALAPPDATA%\BlenderManager (this PC only)

Uninstall: delete the KumikiHub folder. To remove your data too, also delete the other two folders above. Blender itself is not affected.

13FAQ

Will it change my Blender?
It never modifies Blender itself. Changes to settings and add-ons are backed up first, and anything you delete goes to the Safety Bin.
Does it work with the Steam version of Blender?
Not yet. Scans skip the Steam version for now.
How do I report a problem?
About → "Export diagnostics", then email the file to cansss2023@gmail.com. The file never contains API keys or passwords.
